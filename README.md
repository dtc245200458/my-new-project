# Creative Web Design — Website Template nâng cao

Mở index.html trực tiếp bằng trình duyệt. Không cần Internet hay thư viện ngoài.

Đúng cấu trúc website-template-advanced/index.html, css/style.css và images gồm banner.jpg, service1.jpg, service2.jpg, service3.jpg.
Ảnh JPEG minh họa được vẽ riêng và đóng gói đầy đủ.

Giữ nội dung, màu sắc, hiệu ứng và bố cục desktop theo mẫu: header nền ảnh blur 8px và lớp phủ tối; navbar fixed với hover; 3 Cards bằng CSS Grid; Footer 2 cột bằng Flexbox với dấu •.
Bổ sung Media Query dưới hoặc bằng 768px: Card xếp dọc, Footer xếp dọc và menu thu gọn khoảng cách. Ảnh giữ đúng tỷ lệ. Thêm scroll-margin-top để tiêu đề dịch vụ không bị menu che khi nhấn CTA.

Các href="#" và tên mạng xã hội giữ nguyên tính chất minh họa trong đề; chưa có trang Blog hay trang Liên hệ riêng.

Đã kiểm tra cấu trúc HTML, liên kết CSS, đường dẫn ảnh, định dạng JPEG và các quy tắc CSS chính; chưa kiểm tra trực tiếp trên trình duyệt.
Trước khi nộp: mở trang, cuộn để kiểm tra navbar fixed, thử hover nút/Card, nhấn Khám phá ngay và kiểm tra màn hình nhỏ.

Tải cả thư mục website-template-advanced lên GitHub và nộp link thư mục/repository.
