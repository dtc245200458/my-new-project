# Thực hành: Xây dựng Landing Page với Bootstrap

## Chạy bài
Mở index.html bằng trình duyệt có kết nối Internet để tải Bootstrap 5.3.0 từ CDN.

## Nội dung theo mẫu
- Navbar MyBrand, Home, About, Services, Contact; menu collapse cho mobile.
- Hero với tiêu đề, mô tả và nút Khám phá ngay dẫn đến #services.
- Grid gồm 3 cột col-md-4, mỗi cột chứa một Card dịch vụ.
- Footer giữ nguyên nội dung bản quyền 2024 trong đề.
- Bootstrap bundle hỗ trợ nút mở/đóng menu.
- Không cần CSS/JS tùy chỉnh.

Các liên kết Navbar giữ href="#" theo mẫu, chưa dẫn đến trang riêng.

## Kiểm tra trình duyệt trước khi nộp
1. Mở cửa sổ rộng để xem Navbar ngang, Hero, 3 Card và Footer.
2. Nhấn Khám phá ngay để chuyển đến phần dịch vụ.
3. Thu nhỏ dưới 992px, thử mở/đóng Navbar bằng nút menu.
4. Thu nhỏ dưới 768px để kiểm tra các Card xếp dọc.

Đã kiểm tra cấu trúc HTML, tham chiếu CDN, collapse và đích CTA bằng mã nguồn; chưa kiểm tra trực tiếp trên trình duyệt.
