# Phân tích và xây dựng cấu trúc Website Template

Mở index.html bằng trình duyệt, giữ style.css cùng thư mục. Không cần Internet để xem bài dựng lại.
Đọc PHAN-TICH.md để xem phân tích Header, Navigation, Content và Footer của Python.org.
Ảnh original-python.jpg là ảnh chụp toàn trang gốc được đính kèm theo yêu cầu.

Đã quan sát website gốc bằng trình duyệt và chụp ảnh thật. Bản dựng lại chỉ tập trung bố cục, chưa kiểm tra trực quan trên trình duyệt; đã kiểm tra mã nguồn, liên kết nội bộ và tài nguyên.

Tải cả thư mục website-structure-analysis lên GitHub, nộp link thư mục/repository và đính kèm ảnh original-python.jpg nếu hệ thống có ô nộp ảnh riêng. Không bỏ file PHAN-TICH.md và ảnh khi tải lên.
